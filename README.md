Multiplayer Snake Game using AWS

A real-time multiplayer Snake game built using Java sockets and deployed on an AWS EC2 server.

Features
- Multiplayer gameplay
- Snake growth
- Food spawning
- Collision detection
- Score tracking
- Java Swing GUI

Technologies
- Java
- AWS EC2
- TCP sockets
- SSH
- Java Swing
